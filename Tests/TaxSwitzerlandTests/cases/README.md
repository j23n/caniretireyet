# Swiss reference cases

One JSON file per case: a year's inputs and the expected itemised result, worked out by hand or from an official calculator, with the arithmetic written out. The format is the Italian one (`Tests/TaxItalyTests/ReferenceCase.swift`); the drafts are in `docs/tax/drafts/ch-cases.md`. The folder is bundled with the test target (`Bundle.module`, `cases/`).
